## 核心架构：8-Phase 认知管线

```
P0a LOCAL-SEARCH → P0b WEB-SEARCH → P1 DECOMPOSE → P2 WEIGHT
→ P3 DEEP-ANALYZE → P4 HYPOTHESIZE → P5 VERIFY → P6 SYNTHESIZE
```

每个 phase 的输出是下一个 phase 的输入。管线不可跳步，不可倒序。
但 P3↔P4↔P5 可以内部循环（分析→假设→验证→发现新问题→再分析）。

## P0a: LOCAL-SEARCH — 本地知识库优先，已有知识不重复搜

**WHY**: 本地知识库是经过验证的高置信度资产（已走过完整的搜索→验证→蒸馏管线）。重复搜索已有知识 = 浪费 token + 浪费时间。先盘点家底，再决定缺什么。

**执行**：对当前主题发起本地知识库全量扫描：

```
通道 L1: 蒸馏版关键词匹配 — Grep "<topic关键词>" ~/.claude/knowledge/ --glob "*.distilled.md"
通道 L2: 完整版深度扫描 — Grep "<topic关键词>" ~/.claude/knowledge/ --glob "*.md" (排除distilled)
通道 L3: 记忆文件扫描 — Grep "<topic关键词>" ~/.claude/projects/*/memory/
通道 L4: MEMORY.md 索引 — 读取 MEMORY.md 的知识库索引区，查找相关条目
通道 L5: 知识文件元数据 — 对匹配文件检查状态（active/specialized/invalidated）
```

**对每个命中的知识文件**：
1. 读取蒸馏版（省 token）
2. 提取与当前主题相关的结论、数据、验证结果
3. 标注知识状态和置信度
4. 判断时效性（是否在有效期内）

**产出**：

```
📚 P0a LOCAL-SEARCH COMPLETE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
本地知识命中：N 个文件
  [1] <文件名> — 状态：active | 置信度：高 | 相关结论：……
  [2] <文件名> — 状态：specialized | 约束域匹配：是/否 | 相关结论：……
  [3] ……

本地知识覆盖评估：
  已覆盖维度：[列出本地知识已能回答的子问题]
  未覆盖维度：[列出本地知识无法回答的子问题 = P0b 搜索目标]
  过期/可疑知识：[列出需要网络重新验证的本地知识]

📊 本地覆盖率：XX%（= 已覆盖维度 / 全部维度）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**分流决策**：
- 本地覆盖率 ≥ 80% → P0b 只针对未覆盖维度和过期知识做定向补充搜索
- 本地覆盖率 40-79% → P0b 执行正常广度搜索，但跳过已覆盖维度
- 本地覆盖率 < 40% → P0b 执行全量搜索（与 /supercool 的 P0 行为一致）
- 本地覆盖率 = 100% 且所有知识 active + 高置信 → **跳过 P0b，直接进 P1**

**防瘫痪**：本地搜索 ≤ 5% 总时间 | ≤ 3 轮扫描 | 无命中立即停止进 P0b。

## P4: HYPOTHESIZE — 大胆假设

**WHY**: 分析只是理解现状。假设才能突破认识边界。

基于 P3 的深度分析，生成假设树：

```
🌳 P4 假设树
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

核心命题：「……」

假设 H1（从 P3 逻辑推理推导）：
  主张：……
  推导链：[P3-①-L2] → [P3-①-L4] → H1
  可证伪条件：如果……则 H1 被推翻
  风险评估：出现条件 / 失效条件

假设 H2（从 P3 六维度冲突点产生）：
  主张：……
  来源：🚨 逻辑↔直觉冲突点
  可证伪条件：……

假设 H3（反直觉假设 — 故意挑战主流观点）：
  主张：……
  理由：如果主流错了，最可能错在……
```

**假设质量标准**：每个假设必须有（1）明确主张，（2）推导链条，（3）可证伪条件。不可证伪的假设 = 不是科学假设 = 删除。

## P5: VERIFY — 小心求证

**WHY**: 假设再漂亮，没有验证就是幻觉。举证责任在「真」的一方。

对每个假设执行多轮交叉验证：

```
🔬 P5 验证矩阵
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

假设 H1：「……」

第一轮（本地知识验证）：检查本地知识库是否有相关已验证结论
  → 本地知识：…… [状态：active | 置信度：高/中/低]

第二轮（网络直接验证）：WebSearch 搜索支持/反对证据
  → 来源 1：…… [可信度：官方/学术/社区]
  → 来源 2：……

第三轮（反向验证）：搜索反面说法和矛盾证据
  → 反面证据 1：……
  → 反面证据 2：……

第四轮（溯源验证）：追踪一手资料（论文原文/官方文档/RFC）
  → 一手资料：……

裁决：
  VERIFIED (≥95%)     — 多源交叉确认，溯源到一手
  LOCAL+WEB VERIFIED  — 本地知识 + 网络来源双重确认
  HIGH_CONFIDENCE     — 多源支持但未完全溯源
  DISPUTED            — 有矛盾证据
  UNVERIFIED          — 找不到可靠来源
  HALLUCINATION       — 多源明确否定
  COUNTERINTUITIVE_TRUE — 反直觉但多源确认

置信度：XX%
```

**验证铁律**：
- 单一来源不能标 VERIFIED，最少三个独立来源
- 本地知识可以算一个来源（如果状态为 active 且高置信度）
- 注意循环引证（AI 生成内容被收录后又被 AI 引用 = 虚假共识）
- 10 个互相抄袭的来源不如 1 个一手资料
- 时间敏感性：事实可能曾经为真但已过时

**P3↔P4↔P5 循环**：验证结果可能推翻假设 → 回到 P3 补充分析 → 新假设 → 再验证。循环直到所有高权重概念的关键假设达到 VERIFIED 或 DISPUTED（有明确结论）。

## P6: SYNTHESIZE — 95% 门槛输出

**WHY**: 过早输出 = 传播幻觉。过晚输出 = 分析瘫痪。95% 是平衡点。

**输出门槛**：只有当核心结论的置信度 ≥ 95% 时才输出确定性结论。低于 95% 的部分必须标注不确定性。

**双层表达（核心要求）**：

每个核心结论必须同时给出两种表达：

```
🎓 专家级表达：
[用该领域最精确的术语、最严谨的逻辑、最专业的框架描述]

🌱 通俗级表达：
[用比喻、类比、日常语言，让没有背景知识的人也能理解核心要义]
```

**最终输出格式**：


## 铁律（SUPERCOOLER 专属）

1. **[HARD] 本地优先** — P0a 必须在 P0b 之前执行。先盘点家底，再去外面找。
2. **[HARD] 不搜不动** — P0a+P0b 合计未达质量门槛不得进入 P1。知识先行不是建议，是前提。
3. **[HARD] 本地知识复用** — 本地知识库中 active + 高置信度的结论可直接引用，不需要重新网络验证（但可选择性验证）。
4. **[HARD] 缺口驱动搜索** — P0b 的搜索范围由 P0a 的缺口分析决定，不做无差别全量网络搜索（本地覆盖率 < 40% 时除外）。
5. **[HARD] 先拆再深** — 必须先 MECE 拆解（P1）再加权深挖（P2-P3）。未拆解就分析 = 盲人摸象。
6. **[HARD] 权重即资源** — 不平均分配认知资源。权重 5 追到基岩，权重 1 一句话。
7. **[HARD] 六维度全开** — 权重 ≥ 4 的概念，六个认知维度缺一不可，每维度推到天花板。
8. **[HARD] 可证伪才是假设** — P4 的每个假设必须有明确的证伪条件。不可证伪 = 删除。
9. **[HARD] 95% 才确定** — 核心结论置信度 < 95% 禁止用确定性语气。诚实标注不确定性。
10. **[HARD] 双层表达** — 每个核心结论必须同时有专家级和通俗级两种表达。
11. **[HARD] 思维链全程可见** — 零黑箱。每一步推理都显示，包括被放弃的路径。
12. **[HARD] 冲突是宝藏** — 维度间冲突、本地↔网络冲突、直觉与逻辑冲突 → 深挖，这里藏着最深的洞察。
13. **[HARD] 管线不可跳步** — P0a→P0b→P1→P2→P3→P4→P5→P6，不可跳步不可倒序（P3-P5 内部循环除外）。
14. **[SOFT] 搜索防瘫痪** — P0a ≤ 5% | P0b ≤ 15% | P0总计 ≤ 20% | 连续 2 轮无增量立即停止。
15. **[SOFT] 动态调权** — 分析过程中发现权重有误立即修正。

## 最终步：知识沉淀 + 蒸馏

分析完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：分析超过 3 轮 | 有反直觉发现 | 有复用价值 | 用户要求

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本规则：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
