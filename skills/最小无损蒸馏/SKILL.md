你现在进入 **最小无损蒸馏模式** — 将 `.md` 知识文件压缩到极致，几乎不损失语义。

---

## 目标

将 `~/.claude/knowledge/` 中的知识文件（或任意指定的 .md 文件）蒸馏为**信息密度最高、token 占用最小**的形式，使得同样的 context window 能装下更多知识。

**核心约束：压缩后，任何具备领域背景的读者（人或 AI）能还原出与原文等价的完整理解。**

---

## 五层蒸馏流水线

对目标文件，依次执行以下五层压缩，每层在前一层的输出上操作：

### L1：清除装饰性废料
- 删除所有纯装饰元素：`---` 分隔线、空行、无信息 emoji、美化表格框线
- 删除"创建时间"等元数据（用文件名中的日期替代）
- 删除自明的章节标题（如内容只有一句话的 `## 问题描述`，标题本身是废料）

### L2：语言级压缩
- 电报体改写：删除所有不影响语义的虚词、连接词、语气词
- 模式替换：
  - "这个问题的核心本质是 X" → "核心：X"
  - "你需要执行以下步骤" → 删（后面的列表自明）
  - "如果看到错误信息 Y" → "若报错 Y："
  - "需要注意的是" → 删
  - "具体来说" → 删
  - "解决方案是" → "解："
- 使用符号替代文字：→(导致/去) | ≠(不是) | ∵(因为) | ∴(因此) | +(和) | >(大于/优先)

### L3：结构级压缩
- 稀疏表格 → 行内键值对（`key:val | key:val`）
- 只有1-2项的列表 → 合并为一行
- 合并重叠章节（"根因"和"踩坑"中有重复内容 → 合并到一处）
- 代码块只保留核心命令，删除注释和示例输出

### L4：语义去重
- 同一事实在多处出现 → 只保留信息最完整的那一处，其他处删除
- "举一反三"中与"解决方案"重复的经验 → 只保留增量信息
- 多个等价的表述方式 → 只保留最精练的一种

### L5：可推导信息裁剪
- 删除领域内常识（如"HTTP 403 表示权限拒绝"——任何开发者都知道）
- 删除能从上下文 trivially 推导的信息
- 保留**反直觉**的、**容易遗忘**的、**非显而易见**的信息
- 保留所有**具体数值**（端口号、错误码、费率、版本号）——这些无法推导

## 蒸馏后格式规范

```markdown
# [标题——极简一行]
标签：#tag1 #tag2  状态：已解决/待验证

问题：[一句话]
根因：[一句话，点明本质]
解：[步骤用 → 串联，关键命令用 `code`]
坑：[每个坑一行，用 | 分隔独立的坑]
泛化：[仅保留对未来有指导价值的非显然经验]
```

- 全文目标：**不超过原文的 25%**
- 每个字段可以省略（如果该字段没有增量信息）
- 代码块只保留最关键的 1-2 条命令

## 执行流程

### 输入格式

```
/最小无损蒸馏 [文件名或关键词]          → 蒸馏指定文件
/最小无损蒸馏 all                       → 蒸馏 ~/.claude/knowledge/ 下所有文件
/最小无损蒸馏 [任意 .md 文件路径]       → 蒸馏指定路径的文件
```

### 执行步骤

1. **读取**目标文件原文
2. **依次执行** L1→L2→L3→L4→L5 五层压缩
3. **计算压缩率**：蒸馏后字符数 / 原文字符数
4. **语义校验**：逐条对比蒸馏结果与原文，确认无信息丢失。如果某条信息在蒸馏后无法还原出原意 → 加回来
5. **输出对比**：

```
📄 原文：XXX 字符
⚗️ 蒸馏后：YYY 字符（压缩率 ZZ%）
```

6. **蒸馏版写入**：始终写入为 `<原文件名>.distilled.md`（与完整版并存，绝不覆盖完整版）
   - 完整版 `.md` = 人类阅读回溯用
   - 蒸馏版 `.distilled.md` = AI 快速检索加载用
   - **⚠️ 双版本铁律：两版必须同时存在，缺一不可，永远不要用蒸馏版覆盖完整版**

## 质量红线

- **绝对不删**：错误码、端口号、费率、版本号、关键命令、文件路径
- **绝对不删**：反直觉的发现（表象和真因不一致的情况）
- **绝对不删**：踩坑记录中"容易重蹈覆辙"的坑
- **可以删**：过程性描述、常识性解释、重复信息、装饰性内容
