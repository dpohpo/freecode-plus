# Common Skill Combinations

- Browser chat + export + follow-up summarization -> `browser-mcp-operator` + `skill-router`
- Code change + verification -> `verify-change`
- Failure reproduction + diagnosis + fix -> `investigate-failure` + `verify-change`
- Search old context + write new plan -> `searchin` + `skill-router`
- New capability request -> `agent-forge` + `verify-change`
- Multi-agent task coordination -> `blackboard` + `skill-router`
