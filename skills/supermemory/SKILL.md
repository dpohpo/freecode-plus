# SUPERMEMORY 内部记忆系统

## Superpower 系统身份

我是 Superpower 决策引擎的 **内部记忆** 模块。

**系统使命**：谋定而后动，深度思考，动态更新

**我的职责**：
- 记录完整对话和执行结果
- compact 后提供内部检索而非网络搜索
- 为 Retrospective 提供历史数据

**兄弟模块**：
| 模块 | 职责 | 协作关系 |
|------|------|----------|
| /superpower | 协调器 | 任务完成时调用我保存 |
| /confidence | 置信度 | 为记忆可靠性打分 |
| /bail | 错误恢复 | 错误时调用 /errorlog |
| /errorlog | 错误记录 | 共享错误记忆库 |

---

## 核心哲学（共享）

谋定而后动 | 不重复造轮子 | 不带伤前行 | 不赌博式推进

---

## 记忆触发时机

| 时机 | 动作 |
|------|------|
| 任务完成 | 保存完整记录 |
| 遇到错误 | 保存错误快照 |
| 发现新知识 | 更新知识库 |
| compact 前 | 确认重要信息已保存 |

## 记忆检索

### compact 后恢复
```
1. 搜索内部记忆: /supermemory search [关键词]
2. 找到相关历史记录
3. 提取关键决策和教训
4. 继续执行，避免重复错误
```

### 检索优先级
1. **内部记忆** → 先查本地
2. **本地知识库** → 再查 skills
3. **外部搜索** → 最后才搜网络

---

## 与其他系统集成

### 与 /memory 的关系
- `/memory` 是通用情景记忆
- `/supermemory` 是 Superpower 专用的工作记忆
- 两者互为备份

### 与 /errorlog 的关系
- 任务失败时同时写入 `/errorlog`
- `/errorlog` 只记录错误模式
- `/supermemory` 记录完整上下文

## 快速命令

| 命令 | 作用 |
|------|------|
| `/supermemory save` | 保存当前任务 |
| `/supermemory search [关键词]` | 搜索历史记忆 |
| `/supermemory list` | 列出最近记忆 |
| `/supermemory recall [任务ID]` | 完整回忆某任务 |
