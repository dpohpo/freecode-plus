# 报告格式选择与输出生成技能

> **生成日期**: 2026-02-11
> **技能类型**: 分析与决策支持 + 报告生成
> **依赖技能**: /bht, /mecebest, /report-gen

---

## 技能描述

\`\`\`
本技能用于分析用户报告需求，评估最佳输出格式，并生成结构化报告保存到指定目录。

### 核心功能

1. **报告需求深度分析**（使用 /bht）
   - 识别报告类型需求
   - 识别内容复杂度
   - 识别时间敏感度
   - 识别格式要求

2. **格式族MECE分析**（使用 /mecebest）
   - 对格式族进行10维度MECE拆解
   - 评估：Markdown纯、Markdown增强、系统级、图格式、数据格式
   - 生成综合评分和场景匹配

3. **格式推荐生成**
   - 按综合评分排序输出Top 5推荐
   - 为每个推荐提供详细理由

4. **报告自动生成**（使用 /report-gen）
   - 综合所有分析结果
   - 生成结构化报告
   - 保存到 ~/Desktop/报告/ 目录/

## 输入输出规范

### 输入处理

```
📥 用户需求分析
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[用户输入] → [BHT分析] → [MECE格式分析] → [格式评分排序]

输出：Top 5推荐 + 详细理由 + 用户确认
```

### 格式评分系统

**10维度评分标准**：

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| **A. 格式族分类** (15%) | 清晰定义、基础定义、生态成熟度 |
| **B. 人类可读性** (20%) | 所见即所得、工具支持、转换需求、机器友好度 |
| **C. Git友好度** (10%) | 原生支持、版本控制、diff友好度 |
| **D. 双链可靠性** (10%) | 成熟实现、双向链接、断链风险 |
| **E. 可扩展性** (10%) | 插件生态、API开放、自定义能力 |
| **F. 语义强度** (10%) | 元数据支持、查询语言、结构化程度 |
| **G. 工具生态** (10%) | 成熟度、多样性、社区活跃度 |
| **H. 迁移性** (5%) | 数据导入导出、格式转换、供应商锁定 |
| **I. 最佳角色** (5%) | 知识库角色、课程系统、笔记工具、出版系统 |
| **J. 主要代价/坑** (10%) | 学习曲线、配置复杂度、维护成本、已知限制 |
| **K. 推荐场景** (5%) | 个人笔记、团队协作、课程开发、系统集成、API开发 |

**综合分计算** = Σ(维度分 × 权重)

### 格式分类与评分

#### 1. Markdown纯格式族 (82分)

\`\`\`
代表: .md 纯文本

优势: 极简门槛、Git原生支持、可读性强、轻量级
劣势: 缺少结构化、链接依赖手动、语义查询弱
推荐: 快速笔记/个人知识库
\`\`\`

#### 2. Markdown增强格式族 (88分)

\`\`\`
代表: Markdown + WikiLink / Markdown + Frontmatter

优势: 保留MD优势 + 双链支持 + 元数据支持 + 工具生态成熟
劣势: 兼容性问题、依赖特定生态、非标准语法
推荐: 结构化个人知识库
\`\`\`

#### 3. 系统级格式族 (85分)

\`\`\`
代表: Org-mode / Obsidian / Logseq Graph

优势: 强结构化、双链可靠、插件生态丰富、任务集成
劣势: 学习曲线陡峭、Emacs生态依赖、非开发者友好
推荐: 团队协作知识库
\`\`\`

#### 4. 图格式族 (75分)

\`\`\`
代表: Mermaid / DOT (Graphviz)

优势: 可视化清晰、适合流程图、工具支持好
劣势: 不适合大规模存储、编辑器支持有限
推荐: 知识图谱、流程图
\`\`\`

#### 5. 数据格式族 (70分)

\`\`\`
代表: JSON-LD / RDF / CSV

优势: 标准化程度高、API友好、机器可读
劣势: 人类可读性差、需要专门工具、Schema复杂
推荐: 系统集成、API开发
\`\`\`

## 自动决策逻辑

### 推荐算法

```
if (用户报告类型 == "学术论文"):
    推荐格式 = LaTeX (评分90+)
else if (用户报告类型 == "专业出版"):
    推荐格式 = LaTeX (评分90+)
else if (用户需要团队协作):
    推荐格式 = Org-mode系统 (评分85+)
else if (用户需要结构化知识库):
    推荐格式 = Markdown增强 (评分88+)
else:
    推荐格式 = Markdown纯格式 (评分82+)
```

### 默认行为

- 如果用户需求模糊，输出Top 5供选择
- 如果用户明确指定格式，直接使用该格式
- 保存报告到 `~/Desktop/报告/` 目录
