你现在进入 **BACKUP 模式** — 技能包备份工具。

**一句话：把指定技能包复制一份 `<名称>copy`，用于防止误改后无法恢复。**

---

## 使用格式

```
/backup <技能名>
```

### 示例

```
/backup supercool     → 生成 /supercoolcopy
/backup hypothesis    → 生成 /hypothesiscopy
/backup codereview    → 生成 /codereviewcopy
```

---

## 执行流程

### 步骤一：解析参数

从 `$ARGUMENTS` 中提取技能名。如果用户写了 `/`（如 `/supercool`），自动去掉前缀斜杠，只保留纯名称。

- 如果参数为空 → 提示用户：「请指定要备份的技能名，例如 `/backup supercool`」
- 如果参数包含多个技能名 → 逐个处理

### 步骤二：验证源文件存在

检查 `~/.claude/commands/<技能名>.md` 是否存在。

- 存在 → 继续
- 不存在 → 报错：「技能 `/<技能名>` 不存在，无法备份。请用 `ls ~/.claude/commands/` 查看可用技能。」

### 步骤三：检查备份文件是否已存在

检查 `~/.claude/commands/<技能名>copy.md` 是否已存在。

- 不存在 → 继续
- 已存在 → 询问用户：「`/<技能名>copy` 已存在（上次备份）。是否覆盖？」
  - 用户确认 → 覆盖
  - 用户拒绝 → 中止

### 步骤四：执行备份

1. 读取 `~/.claude/commands/<技能名>.md` 的完整内容
2. 将内容原样写入 `~/.claude/commands/<技能名>copy.md`
3. **不做任何修改** — 逐字节复制，保持100%一致

### 步骤五：验证

读取 `<技能名>copy.md` 的前3行，确认写入成功。

### 步骤六：输出结果

```
✅ 备份完成
📄 源文件：~/.claude/commands/<技能名>.md
📋 备份文件：~/.claude/commands/<技能名>copy.md
🔄 恢复命令：/backwards <技能名>
```

---

## 铁律

1. **原样复制** — 备份文件必须与源文件100%一致，不增不减不改
2. **先检查后写入** — 必须先验证源文件存在，再执行复制
3. **已有备份必须询问** — 覆盖旧备份前必须得到用户确认
4. **命名规则固定** — 备份文件名 = `<原名>copy.md`，不可自定义

## 最终步：知识沉淀 + 蒸馏

分析/任务完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：
- 排查超过 3 轮对话
- 涉及配置/权限/环境等易忘细节
- 根因反直觉（表象 ≠ 真因）
- 跨系统联调问题
- 用户要求存入

**不存条件：** 一句话能答的简单问题 | 纯知识查询 | 无复用价值

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本铁律：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
