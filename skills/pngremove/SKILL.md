你现在进入 **PNGREMOVE 模式** — 桌面 PNG 扫描清理工具。

---

## 核心能力

扫描指定目录（默认 `~/Desktop`）中的 PNG 文件，列出清单，经用户确认后批量删除。主要用于清理 Peekaboo 截屏、调试截图等临时 PNG。

---

## 执行流程

### 第一步：扫描

使用 Glob 工具扫描目标目录中的 `.png` 文件（仅顶层，不递归子目录）：

```
Glob pattern="*.png" path="~/Desktop"
```

### 第二步：列出清单

将扫描结果以表格形式呈现：

```
🔍 PNG 扫描结果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📁 扫描目录：~/Desktop
📊 找到：[N] 个 PNG 文件

│ # │ 文件名                        │ 大小      │ 修改时间           │
│───│──────────────────────────────│──────────│───────────────────│
│ 1 │ xxx.png                       │ 1.2 MB   │ 2026-02-06 00:36  │
│ 2 │ yyy.png                       │ 530 KB   │ 2026-02-06 00:42  │
│...│                               │          │                   │

💾 总大小：[X] MB
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 第三步：确认删除

**[HARD] 删除前必须获得用户明确确认。**

向用户展示清单后，使用 AskUserQuestion 询问：

- **全部删除** — 删除所有扫描到的 PNG
- **选择删除** — 用户指定要删除的文件编号
- **取消** — 不删除任何文件

### 第四步：执行删除

用户确认后，使用 `rm` 逐个删除确认的文件。

**[HARD] 安全规则：**
- 只删除 `.png` 后缀的文件
- 只删除扫描清单中列出的文件（不接受通配符）
- 不递归删除子目录中的文件
- 每个 `rm` 命令只删除单个文件，不使用 `rm -rf` 或 `rm *.png`
- 删除后立即验证文件已不存在

### 第五步：报告

```
🗑️ PNG 清理完成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 已删除：[N] 个文件
💾 释放空间：[X] MB
❌ 跳过：[M] 个文件（用户选择保留）
⚠️ 失败：[K] 个文件（如有，列出原因）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 参数扩展

用户可在调用时指定不同目录：

```
/pngremove                    → 默认扫描 ~/Desktop
/pngremove ~/Downloads        → 扫描 Downloads
/pngremove ~/Desktop ~/Downloads  → 扫描多个目录
```

---

## 铁律

1. **[HARD] 删除前必须确认** — 永远不跳过用户确认步骤，即使用户在调用时说了「全部删除」
2. **[HARD] 单文件删除** — 每次 `rm` 只删一个文件，不使用通配符
3. **[HARD] 仅限 PNG** — 只处理 `.png` 后缀文件，不扩展到其他格式
4. **[HARD] 不递归** — 默认只扫描顶层目录，不进入子目录（除非用户明确要求）
5. **[SOFT] 先展示后行动** — 先完整列出所有文件，再询问操作

## 最终步：知识沉淀 + 蒸馏

清理完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：发现异常大量 PNG 堆积的原因 | 清理过程中发现重要文件被误标为临时 | 用户要求

**不存条件：** 常规清理无特殊发现

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本铁律：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
