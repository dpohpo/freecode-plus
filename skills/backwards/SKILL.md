你现在进入 **BACKWARDS 模式** — 技能包回滚工具。

**一句话：用 `<名称>copy` 备份覆盖回 `<名称>`，将技能恢复到备份时的状态。**

---

## 使用格式

```
/backwards <技能名>
```

### 示例

```
/backwards supercool     → 用 /supercoolcopy 恢复 /supercool
/backwards hypothesis    → 用 /hypothesiscopy 恢复 /hypothesis
/backwards codereview    → 用 /codereviewcopy 恢复 /codereview
```

---

## 执行流程

### 步骤一：解析参数

从 `$ARGUMENTS` 中提取技能名。如果用户写了 `/`（如 `/supercool`），自动去掉前缀斜杠。也支持用户直接写 copy 名（如 `supercoolcopy`），自动去掉 `copy` 后缀还原为原始技能名。

- 如果参数为空 → 提示用户：「请指定要回滚的技能名，例如 `/backwards supercool`」

### 步骤二：验证备份文件存在

检查 `~/.claude/commands/<技能名>copy.md` 是否存在。

- 存在 → 继续
- 不存在 → 报错：「备份 `/<技能名>copy` 不存在。请先用 `/backup <技能名>` 创建备份。」

### 步骤三：验证源文件存在

检查 `~/.claude/commands/<技能名>.md` 是否存在。

- 存在 → 继续（将被覆盖）
- 不存在 → 警告用户：「原技能 `/<技能名>` 已不存在，将从备份重新创建。是否继续？」

### 步骤四：展示差异（安全确认）

对比 `<技能名>.md`（当前版本）和 `<技能名>copy.md`（备份版本）：

1. 如果两者完全一致 → 告知用户「当前版本与备份一致，无需回滚」，结束
2. 如果不一致 → 显示摘要差异（行数变化、关键改动），询问用户：「确认用备份版本覆盖当前版本？此操作不可撤销（当前版本将丢失）。」
   - 用户确认 → 继续
   - 用户拒绝 → 中止

### 步骤五：执行回滚

1. 读取 `~/.claude/commands/<技能名>copy.md` 的完整内容
2. 将内容原样写入 `~/.claude/commands/<技能名>.md`（覆盖当前版本）
3. **不做任何修改** — 逐字节还原，保持与备份100%一致

### 步骤六：验证

读取恢复后的 `<技能名>.md` 的前3行，确认写入成功。

### 步骤七：清理询问

询问用户：「回滚完成。是否保留备份文件 `/<技能名>copy`？」

- 保留 → 不动（可用于再次回滚）
- 删除 → 删除 `<技能名>copy.md`

### 步骤八：输出结果

```
✅ 回滚完成
📄 已恢复：~/.claude/commands/<技能名>.md
📋 备份源：~/.claude/commands/<技能名>copy.md
🕐 恢复到：备份时的版本
```

---

## 铁律

1. **原样还原** — 恢复文件必须与备份文件100%一致，不增不减不改
2. **先确认后覆盖** — 覆盖当前版本前必须得到用户明确确认
3. **差异可见** — 回滚前必须展示当前版本与备份版本的差异摘要
4. **备份不存在则拒绝** — 没有备份就没有回滚，不猜测、不编造
5. **清理可选** — 回滚后是否删除备份由用户决定

## 最终步：知识沉淀 + 蒸馏

分析/任务完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：
- 排查超过 3 轮对话
- 涉及配置/权限/环境等易忘细节
- 根因反直觉（表象 ≠ 真因）
- 跨系统联调问题
- 用户要求存入

**不存条件：** 一句话能答的简单问题 | 纯知识查询 | 无复用价值

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本铁律：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
