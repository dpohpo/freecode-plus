### 第四阶段：事实声明提取与求真验证

从六维度推演结论中，提取所有涉及**外部事实**的关键声明，进入求真验证：

```
🔍 事实声明提取
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

│ # │ 声明                │ 可疑度 │ 可疑原因          │
│───│────────────────────│───────│──────────────────│
│ 1 │ [从推演中提取的声明]  │ 高/中/低│ [为什么可疑]       │
│ 2 │ ……                 │       │                  │
```

对每个声明执行**多轮网络交叉验证**：

1. **第一轮：直接搜索** — 用 WebSearch 搜索声明核心事实
2. **第二轮：反向搜索** — 搜索声明的反面或替代说法
3. **第三轮：溯源搜索** — 追踪原始出处，查找一手资料

每轮记录来源可信度等级（官方/权威媒体/学术/社区/不明）。

**六级裁决：**

| 裁决类型 | 条件 | 标记 |
|---------|------|------|
| **石锤幻觉** | 多个可靠来源明确否定，无可靠来源支持 | HALLUCINATION |
| **高度可疑** | 找不到来源支持，无明确否定 | SUSPICIOUS |
| **证据不足** | 有零星支持但无法溯源一手资料 | UNVERIFIED |
| **合理推断** | 无直接证据，但可从已验证事实推导 | INFERRED |
| **反直觉但真实** | 违反常识但多个可靠来源确认 | COUNTERINTUITIVE_TRUE |
| **事实确认** | 多个独立可靠来源交叉确认 | VERIFIED |

**求真原则：**
- 宁可误判为可疑，不可放过幻觉
- 10 个互相抄袭的来源不如 1 个一手资料
- 注意循环引证（AI生成→收录→AI再引用=虚假共识）
- 时间敏感性——曾经为真可能已过时
- 禁止仅凭自身知识下结论，必须用 WebSearch/WebFetch 实际验证

## 铁律

1. **六维度全开** — 对高权重概念，六个认知维度缺一不可
2. **每维度推到天花板** — 不是「想了一下」，是「想到这个维度不可能再深了」
3. **维度间必须交叉** — 单维度再深也可能是偏的，交叉验证才可靠
4. **元认知不可省略** — 必须审查自己的思维模式和认知偏差
5. **冲突是宝藏** — 维度间的冲突点往往藏着最深刻的洞察
6. **低权重不浪费** — 认知极限只用在值得的概念上
7. **推演之后必求真** — 六维度推演完成后，关键外部事实声明必须经网络验证
8. **禁止自证** — 不能用自身训练知识验证自身训练知识，必须用外部来源
9. **宁可误判不放过** — 对幻觉零容忍，可疑即标注
10. **溯源到一手** — 一手资料（官方文档/原始论文）优先于一切转述
11. **⚡ 95%置信度铁律** — 置信度<95%禁止确定性语气，涉及外部系统必须先验证后行动
12. **禁止疯狂测试** — 先查官方文档，再写代码/配置，不要"试试看"

## 最终步：知识沉淀 + 蒸馏

分析完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：分析超过 3 轮 | 有反直觉发现 | 发现石锤幻觉 | 有复用价值 | 用户要求

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本规则：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
