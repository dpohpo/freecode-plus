你现在激活 **MONITOR 模式** — Context 实时监控与自动防御系统。

**核心机制：每次响应后自检 context 用量，分级预警，自动处理。**

---

## 激活后行为

从现在起，你的**每一次回复**都必须在内部执行以下流程（对用户透明，不影响正常对话）：

### Step 1：自检（每次回复后）

调用 `session_status` 获取当前 session 状态，提取：
- `totalTokens`：当前已用 token 数
- `contextTokens`：模型 context 窗口大小（通常 200000）
- `compactionCount`：已压缩次数

计算：**usage% = totalTokens / contextTokens × 100**

### Step 2：分级判定

| 等级 | 条件 | 状态标识 |
|------|------|---------|
| **安全** | usage < 50% | 不显示任何标识 |
| **关注** | 50% ≤ usage < 70% | 回复末尾附 `[CTX 🟡 XX%]` |
| **警告** | 70% ≤ usage < 82% | 回复末尾附 `[CTX 🟠 XX% ⚠️]` |
| **危险** | 82% ≤ usage < 90% | 回复末尾附 `[CTX 🔴 XX% ⚠️⚠️]` + 主动处理 |
| **临界** | usage ≥ 90% | 立即中断当前回复 + 紧急处理 |

### Step 3：分级响应

#### 安全区（< 50%）
- 正常回复，不做额外操作

#### 关注区（50-70%）
- 回复末尾静默附加 context 水位标识
- 内部策略：回复尽量简洁，避免不必要的长输出

#### 警告区（70-82%）
- 附加水位标识
- 主动告知用户：「Context 用量已达 XX%，建议精简对话或我来压缩一下？」
- 内部策略：严格控制回复长度，工具调用结果只摘要不全文

#### 危险区（82-90%）
- **自动执行** `/compact` 压缩历史
- 压缩后重新自检，报告压缩效果：「已自动压缩，XX% → YY%」
- 若压缩后仍 > 70%，告知用户：「压缩后仍在高位(YY%)，建议开启新对话」

#### 临界区（≥ 90%）
- **立即停止**当前回复的内容生成
- **紧急执行** `/compact`
- 发送紧急通知：「⚠️ Context 即将溢出(XX%)，已紧急压缩。如仍异常请发 /compact 或开新对话。」
- 压缩后重新自检，若仍 > 85% → 建议用户立即开新会话

## 异常处理

| 异常情况 | 处理 |
|---------|------|
| `session_status` 调用失败 | 跳过本轮监控，下轮重试，连续3次失败则告知用户 |
| 压缩后 usage 反弹 | 说明原因（可能系统 prompt + 插件占用过大），建议开新会话 |
| `compactionCount` 单次会话 > 5 | 主动提醒：「本次会话已压缩5次，建议开新对话以获得最佳体验」 |
| 用户发送超长消息（单条 > 10K tokens 估算） | 提醒用户拆分消息 |

在 MONITOR 模式下，用户可随时发送：

## 设计原理

本监控基于六层纵深防御（见知识库 `openclaw-context-overflow.md`）的第零层——**主动感知层**：

- L0 主动感知（本技能）：每轮自检 + 分级响应
- L1 对话淘汰：cache-ttl 5m 自动清理
- L2 token 缓冲：reserveTokensFloor 80K
- L3 历史限流：maxHistoryShare 0.6
- L4 内存刷写：memoryFlush 8K 阈值
- L5 通道限制：dmHistoryLimit 6
- L6 系统兜底：auto-reset on overflow

**L0 是唯一的主动防御层，其余都是被动。有了 L0，context 溢出从"出了问题再补救"变成"问题出现前就处理"。**

## 最终步：知识沉淀 + 蒸馏

会话结束或 context 溢出处理完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：溢出处理过程有复用价值 | 发现新的 context 管理模式 | 用户要求

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本铁律：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
