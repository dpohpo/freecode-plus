你现在进入 **LITE 模式** — 轻量快速执行系统。

**一句话：扫一眼→列3步→做→验。不深挖，不搜全网，不MECE。快准稳。**

适用场景：3-8步的中等任务。更简单的（1-2步）不需要模式。更复杂的（>8步/未知）应升级到 /superplaner 或 /supercooler。

```bash
python3 ~/Desktop/mode-manager.py activate lite S1 "$ARGUMENTS"
```

## 执行流程：S1 → S2 → S3 → S4

### S1: SCAN — 快速扫描（≤1分钟）

回答3个问题，每个1句话：
1. **目标**：要做什么？（1句话）
2. **已知**：我已经知道什么？（本地知识/上下文）
3. **缺口**：我缺什么？（需要搜索或确认的）

如果缺口涉及外部事实 → **1次** WebSearch 补缺，不超过1次。
如果无缺口 → 直接进 S2。

```bash
python3 ~/Desktop/mode-manager.py update S2
```

### S2: PLAN — 3步计划（≤30秒）

列出 **最多3个步骤**，每步1行：

```
步骤1: [动作] → [预期结果]
步骤2: [动作] → [预期结果]
步骤3: [动作] → [预期结果]
```

铁律：
- 超过3步 → 这不是LITE任务，建议升级
- 每步必须有明确的预期结果（不允许模糊的"应该会"）
- 有依赖关系 → 标注顺序

```bash
python3 ~/Desktop/mode-manager.py update S3
```

### S3: DO — 执行（主体）

按 S2 计划顺序执行。每步完成后1行确认：

```
✓ 步骤1: [实际结果] — 符合预期 / ⚠️ 偏差: [描述]
```

**偏差处理**（轻量版）：
- 小偏差（不影响目标）→ 记录，继续
- 大偏差（影响目标）→ 停下，调整计划，重列步骤
- 连续2次失败 → mode-manager.py 会自动触发升级提醒，听它的

```bash
python3 ~/Desktop/mode-manager.py update S4
```

### S4: VERIFY — 验证（≤30秒）

1行回答：**目标达成了吗？** 是/否 + 证据。

- 是 → 完成，清除模式
- 否 → 判断：修一下能搞定（回S3）还是需要更强模式（建议升级）

```bash
python3 ~/Desktop/mode-manager.py clear
```

## 铁律（LITE 专属，共5条）

1. **不深挖** — 无六维度认知、无MECE拆解、无基岩追问。这些是 /supercool* 的事。
2. **不广搜** — 最多1次 WebSearch。多轮搜索是 /supercooler 的事。
3. **3步上限** — 计划超过3步 = 不是LITE任务，建议升级。
4. **快速失败** — 执行中连续失败2次（mode-manager自动检测），立即建议升级到full模式。
5. **1行确认** — 每步执行后1行确认结果，不写长报告。

## 最终步：知识沉淀 + 蒸馏

LITE 模式的沉淀条件更严格（大部分LITE任务不值得存）：

**存入条件**（必须满足至少2项）：
- 执行中遇到反直觉问题
- 涉及易忘的配置/权限细节
- 用户要求存入

**不存条件**：一步搞定的 | 结果符合预期的 | 无复用价值的

**执行流程**（同全局标准）：
1. 问用户：「要存入知识库吗？」
2. 若是 → 完整版 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md` + 蒸馏版 `.distilled.md`
