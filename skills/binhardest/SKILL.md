# 第一阶段：方案穷举（HARDEST 思维）

Think deep, deeper, and deepest. Try hardest. Push your knowledge and cognition to the absolute limits of your boundaries.

## 核心目标

穷举目标软件/工具的**所有可行安装方式**，不遗漏任何一种。

## 穷举要求

1. **全面搜索** — 必须使用 WebSearch 搜索多轮，覆盖：
   - 官方推荐方式
   - 包管理器（brew, apt, yum, pacman, scoop, choco, winget, nix, conda, pip, npm, cargo 等，凡是适用的都列出）
   - 源码编译
   - Docker / 容器化
   - 预编译二进制下载
   - 版本管理器（asdf, mise, nvm, pyenv, rustup 等）
   - GUI 安装器（.dmg, .exe, .AppImage 等）
   - 其他非主流但可行的方式
2. **不放过边缘方案** — 哪怕是冷门方式，只要技术上可行就列出
3. **版本敏感** — 注意区分安装的版本差异（stable / LTS / nightly / edge）

## 对比维度

对所有方案进行**严格对比**，维度至少包括：

| 维度 | 说明 |
|------|------|
| **安装复杂度** | 步骤数、是否需要前置依赖、新手友好程度（1-5星） |
| **卸载干净度** | 卸载是否干净、残留文件多不多 |
| **版本管理** | 能否方便切换/升级/降级版本 |
| **系统侵入性** | 是否修改系统环境变量、PATH、全局配置 |
| **隔离性** | 是否与系统其他软件隔离，会不会产生依赖冲突 |
| **更新便利性** | 后续更新是否方便 |
| **社区主流度** | 这种方式在社区中的使用比例和推荐度 |
| **平台兼容性** | 是否跨平台、在当前用户 OS 上是否可用 |
| **速度** | 安装速度（下载量、编译时间等） |
| **可靠性** | 安装失败概率、已知坑 |

# 第二阶段：安装执行（NOOBINSTALL 模式）

用户选择方案后，立即切换为 **NOOBINSTALL 模式**，按以下规则执行：

## 核心原则

1. **一次只说一个步骤。** 绝对禁止一次给出多个步骤。每条消息只包含一个明确的动作。
2. **每步必须验证。** 每个步骤完成后，要求用户提供验证（截图、复制粘贴输出、或其他可确认的证据）。只有确认当前步骤成功，才进入下一步。
3. **零跳跃。** 不允许 skip 任何步骤，不允许说"如果你已经做过就跳过"。每一步都走，每一步都验证。
4. **说人话。** 不用术语，或者用了术语必须立刻用大白话解释。假设用户从未用过终端、从未装过任何东西。
5. **预判错误。** 每个步骤都要提前告知"你应该看到什么"和"如果看到别的东西怎么办"。
6. **进度感。** 每步开头标注"第 X 步 / 共 Y 步"，让用户知道进度。如果总步数在过程中变化，及时更新。

## 消息格式模板

每条消息严格按以下格式：

```
📌 第 X 步 / 共 Y 步：[步骤标题]

[做什么，用最简单的语言]

[如果需要输入命令，给出完整可复制的命令]

✅ 你应该看到：[预期结果描述]
❌ 如果看到别的：[常见错误及处理方法]

👉 完成后请 [截图给我 / 把输出复制粘贴给我 / 告诉我你看到了什么]
```

## 验证方式（按优先级）

1. 截图（最直观）
2. 复制粘贴命令输出
3. 回答确认问题（"你看到了 XXX 吗？"）
4. 执行验证命令并贴结果

## 对 AI 的额外指令

- 你自己也要用工具去验证（网络搜索确认命令正确、本地执行确认路径存在等）
- 不确定的命令先自己验证再给用户
- 如果安装过程中发现需要额外前置步骤，立即插入并更新总步数
- 最终验证：安装完成后做一次完整功能测试

## 最终步：知识沉淀 + 蒸馏

安装完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：安装过程有坑 | 方案对比有复用价值 | 用户要求

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-install-<软件名>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-install-<软件名>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本规则：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
