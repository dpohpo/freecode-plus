你现在进入 **MINUS 模式** — 技能包差集工具。

你的任务是从技能A中**减去技能B覆盖的部分**，生成一个只保留A独有能力的新技能包，写入 `~/.claude/commands/`。

> 与 `/merge` 的关系：`/merge` = A ∪ B（并集），`/minus` = A \ B（差集）。互为逆运算。
> 验证等式：如果 `/merge B result = A`，那么 `/minus A B = result` 应成立。

### 🧬 铁律传染性（核心功能）

**本技能具有铁律传染性 — 它产出的每一个新技能都会被自动植入全部铁律。**

传染内容（从 `~/.claude/CLAUDE.md` 读取最新版本）：
1. 反幻觉铁律头部（2 行精简版，写入新技能第 1-2 行）
2. 编码铁律+自审清单（3 行精简版，写入新技能第 4-6 行）
3. 知识沉淀+蒸馏流程（写入新技能尾部）

**传染铁律：**
- 产出前必须读取 `~/.claude/CLAUDE.md` 获取最新铁律版本，不使用缓存/记忆中的旧版
- 产出文件第一行必须是反幻觉铁律，无例外
- 缺少任何一层铁律的产出 = 不合格，必须修复后才能写入

## 输入格式

```
/minus A B [> 新技能名]
```

- **A** = 被减数技能（保留其独有部分）
- **B** = 减数技能（从A中移除B覆盖的部分）
- `> 新技能名` 可选，指定输出文件名。如不指定，自动命名为 `A_minus_B`

### 示例

```
/minus best broadest              → 生成 best 减去 broadest 的差集（≈ deepest 的独有能力）
/minus best broadest > deepest2   → 同上，但输出命名为 deepest2
/minus mecehardest mece           → 提取 mecehardest 中 mece 以外的部分（≈ hardest 的独有能力）
/minus supercool deepest          → 提取 supercool 中 deepest 以外的部分
```

## 执行流程

### 步骤一：加载源文件

1. 解析 `$ARGUMENTS`，提取技能A（被减数）、技能B（减数）、可选输出名
2. 对A和B，**读取** `~/.claude/commands/<技能名>.md` 的完整内容
3. 文件不存在 → 列出 `~/.claude/commands/` 下所有可用技能，让用户重新选择
4. 全部加载成功后，进入差集流程

> **铁律：必须读取源文件原文，不凭记忆，不凭猜测。**

### 步骤二：原子化解构（MECE）

对A和B分别执行拆解：

1. 提取**原子指令**（不可再分的最小指令单元）
2. 每条标注**六维分类**：
   - `[身份]` 你是谁 — 角色、能力声明
   - `[思维]` 怎么想 — 推理框架、分析方法
   - `[行为]` 怎么做 — 操作步骤、工作流
   - `[验证]` 怎么确认 — 验证方法、终止条件
   - `[输出]` 怎么呈现 — 格式、结构
   - `[约束]` 不能做什么 — 限制、边界
3. 每条标注**来源**：`[源:A]` 或 `[源:B]`

### 步骤三：重叠检测

对A的每条原子指令，与B的所有原子指令比对，判定三种关系：

| 关系 | 定义 | 操作 |
|------|------|------|
| **完全重叠** | A的指令与B的某条在语义上等价（措辞不同但含义相同） | 从A中**移除** |
| **部分重叠** | A的指令包含B的某条能力，但还有B未覆盖的额外部分 | **保留差异部分**，移除重叠部分 |
| **无重叠** | A的指令在B中完全没有对应 | **完整保留** |

**重叠判定标准**：
- 语义等价，不是字面等价。「先搜索再分析」和「搜索优先于分析」= 重叠
- 同维度同功能 = 重叠。不同维度 = 不重叠
- 拿不准 → 保守保留（宁可多留，不可误删）

### 步骤四：差集提取

1. 收集A中所有**无重叠**的原子指令 → 完整保留
2. 收集A中所有**部分重叠**的原子指令 → 提取差异部分
3. 丢弃A中所有**完全重叠**的原子指令
4. 输出差集统计：

```
📊 差集统计
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A 原子指令总数：X
B 原子指令总数：Y
完全重叠（已移除）：M
部分重叠（已裁剪）：N
无重叠（完整保留）：P
差集指令总数：P + N = Z
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 步骤五：合成新技能文本

将差集原子指令重新组装为一篇**流畅、自然、可直接作为 prompt 使用**的技能文档：

**合成原则：**
- 身份声明：基于A的身份，减去B覆盖的能力描述，重写为差集能力
- 思维框架：保留A独有的推理方法，移除与B共享的
- 行为步骤：重组为独立的工作流，确保流程完整可用
- 验证方法：保留A独有的验证手段
- 约束条件：保留A独有的约束
- 输出格式：适配差集内容调整输出格式

**文本要求：**
- 写成完整、独立的技能 prompt，不引用或依赖源技能文件
- 风格与现有技能包保持一致
- 末尾包含 `$ARGUMENTS` 占位符
- 不包含任何关于差集过程本身的说明（用户看到的是成品）

### 步骤六：完整性验证

差集后的技能必须仍然是一个**可独立使用的完整技能**：

| 检查项 | 标准 | 不通过时 |
|--------|------|---------|
| 工作流完整性 | 从输入到输出是完整闭环 | 补充缺失的连接步骤 |
| 身份自洽 | 身份声明与实际能力匹配 | 重写身份声明 |
| 步骤连贯 | 每步的输入来自前步的输出 | 补充断裂的步骤 |
| 最小可用 | 差集技能至少有 1 个独有的核心能力 | 警告用户：差集为空或过小 |

**关键原则：差集不能产出残缺品。** 如果移除重叠后剩余部分不能独立成技能（缺乏基本工作流），必须：
1. 补充最小必要的连接逻辑（标注为 `[补充：差集完整性]`）
2. 告知用户补充了什么，为什么

### 步骤七：写入文件

1. 将最终文本写入 `~/.claude/commands/<新技能名>.md`
2. 如果目标文件已存在 → **先告知用户，询问是否覆盖**
3. 写入成功后输出：

```
✅ 已生成差集技能包：/<新技能名>
➖ 差集运算：/<A> \ /<B>
📄 文件：~/.claude/commands/<新技能名>.md
📊 差集统计：A有X条 → 移除M条重叠 → 保留Z条独有
🔒 内置：反幻觉铁律 + 知识沉淀蒸馏流程

现在可以直接使用 /<新技能名> 了。
```

## 铁律

1. **先读后减** — 必须读取A和B的原文，不凭记忆做差集
2. **语义等价判定** — 重叠是语义级的，不是字面级的。相同含义不同措辞 = 重叠
3. **保守保留** — 拿不准是否重叠 → 保留在差集中（宁多勿少）
4. **差集必须可用** — 产出必须是完整可用的独立技能，不能是残缺片段
5. **反幻觉铁律必须在头部** — 产出文件第一行必须是反幻觉铁律，无例外
6. **知识沉淀+蒸馏必须在尾部** — 产出文件最后必须是知识沉淀流程，无例外
7. **不可逆验证** — 差集完成后，心理验证：`/merge B result ≈ A` 是否大致成立？不成立 → 回查

## 最终步：知识沉淀 + 蒸馏

差集完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：
- 排查超过 3 轮对话
- 涉及配置/权限/环境等易忘细节
- 根因反直觉（表象 ≠ 真因）
- 跨系统联调问题
- 用户要求存入

**不存条件：** 一句话能答的简单问题 | 纯知识查询 | 无复用价值

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本铁律：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
