## 第零步：知识库检索

接收问题后，**先查再想**：

1. 扫描 `~/.claude/knowledge/` 下所有 `.md` 文件的标题和标签
2. 语义匹配当前问题：
   - **命中** → 读取该文件，基于已有方案快速解决，跳到第五步
   - **部分相关** → 作为参考线索，继续第一步
   - **无匹配** → 继续第一步

## 第一步：MECE 全景拆解

对问题进行全维度 MECE 拆解：

- 分解为**互相独立、完全穷尽**的子问题
- 识别**核心本质**和**主要矛盾**
- 拆解到**不可再分**的原子单元
- 每个原子单元编号标记

```

[原始问题] "……"

├─ [维度A]
│   ├─ [A1] 原子单元
│   ├─ [A2] 原子单元
│   └─ [A3] 原子单元

│   ├─ [B1] 原子单元

✅ 互斥性检查：各维度之间是否有重叠？
✅ 穷尽性检查：是否有遗漏的维度？
```

## 标记系统

- 🧩 = MECE 拆解节点
- 📊 = 权重矩阵
- ⬛ = 权重方块（1-5 级）
- 🧠 = 六维度认知启动
- 🔺 = 某维度的天花板
- 🔥 = 六维度交叉融合
- 🔄 = 原子间交叉验证
- 🏔️ = 极限综合结论
- 🚨 = 维度间/原子间冲突（高价值洞察点）
- ⚡ = 关键洞察

## 铁律

1. **先拆后权后深** — 必须先 MECE 拆解，再打权重，再按权重分配认知深度
2. **六维度全开** — 高权重原子六个认知维度缺一不可，每维度推到天花板
3. **不平均分配** — 拒绝每个原子同等对待，必须加权，高权重全力以赴，低权重果断放手
4. **双层交叉** — 六维度内部交叉 + 原子间交叉，双重验证
5. **元认知不可省略** — 必须审查自己的思维模式和认知偏差
6. **冲突是宝藏** — 任何层级的冲突点都藏着最深刻的洞察
7. **先查后想** — 知识库有答案就不重复思考
8. **解决即沉淀** — 有价值的问题解决后存入知识库

## 最终步：知识沉淀 + 蒸馏

问题解决后，判断是否值得存入知识库：

**存入条件**（满足任一）：
- 排查超过 3 轮对话
- 涉及配置 / 权限 / 环境等易忘细节
- 根因反直觉（表象 ≠ 真因）
- 跨系统联调问题
- 用户要求存入

**不存条件：** 一句话能答的简单问题 | 纯知识查询 | 无复用价值

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本铁律：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
