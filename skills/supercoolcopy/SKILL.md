## 核心架构：7-Phase 认知管线

```
P0 SEARCH  → P1 DECOMPOSE → P2 WEIGHT → P3 DEEP-ANALYZE
→ P4 HYPOTHESIZE → P5 VERIFY → P6 SYNTHESIZE
```

每个 phase 的输出是下一个 phase 的输入。管线不可跳步，不可倒序。
但 P3↔P4↔P5 可以内部循环（分析→假设→验证→发现新问题→再分析）。

## P4: HYPOTHESIZE — 大胆假设

**WHY**: 分析只是理解现状。假设才能突破认识边界。

基于 P3 的深度分析，生成假设树：

```
🌳 P4 假设树
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

核心命题：「……」

假设 H1（从 P3 逻辑推理推导）：
  主张：……
  推导链：[P3-①-L2] → [P3-①-L4] → H1
  可证伪条件：如果……则 H1 被推翻
  风险评估：出现条件 / 失效条件

假设 H2（从 P3 六维度冲突点产生）：
  主张：……
  来源：🚨 逻辑↔直觉冲突点
  可证伪条件：……

假设 H3（反直觉假设 — 故意挑战主流观点）：
  主张：……
  理由：如果主流错了，最可能错在……
```

**假设质量标准**：每个假设必须有（1）明确主张，（2）推导链条，（3）可证伪条件。不可证伪的假设 = 不是科学假设 = 删除。

## P5: VERIFY — 小心求证

**WHY**: 假设再漂亮，没有验证就是幻觉。举证责任在「真」的一方。

对每个假设执行多轮交叉验证：

```
🔬 P5 验证矩阵
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

假设 H1：「……」

第一轮（直接验证）：WebSearch 搜索支持/反对证据
  → 来源 1：…… [可信度：官方/学术/社区]
  → 来源 2：……

第二轮（反向验证）：搜索反面说法和矛盾证据
  → 反面证据 1：……
  → 反面证据 2：……

第三轮（溯源验证）：追踪一手资料（论文原文/官方文档/RFC）
  → 一手资料：……

裁决：
  VERIFIED (≥95%)     — 多源交叉确认，溯源到一手
  HIGH_CONFIDENCE     — 多源支持但未完全溯源
  DISPUTED            — 有矛盾证据
  UNVERIFIED          — 找不到可靠来源
  HALLUCINATION       — 多源明确否定
  COUNTERINTUITIVE_TRUE — 反直觉但多源确认

置信度：XX%
```

**验证铁律**：
- 单一来源不能标 VERIFIED，最少三个独立来源
- 注意循环引证（AI 生成内容被收录后又被 AI 引用 = 虚假共识）
- 10 个互相抄袭的来源不如 1 个一手资料
- 时间敏感性：事实可能曾经为真但已过时

**P3↔P4↔P5 循环**：验证结果可能推翻假设 → 回到 P3 补充分析 → 新假设 → 再验证。循环直到所有高权重概念的关键假设达到 VERIFIED 或 DISPUTED（有明确结论）。

每个核心结论必须同时给出两种表达：

```

🌱 通俗级表达：
[用比喻、类比、日常语言，让没有背景知识的人也能理解核心要义]
```

## 铁律（SUPERCOOL 专属）

1. **[HARD] 不搜不动** — P0 未达质量门槛不得进入 P1。知识先行不是建议，是前提。
2. **[HARD] 先拆再深** — 必须先 MECE 拆解（P1）再加权深挖（P2-P3）。未拆解就分析 = 盲人摸象。
3. **[HARD] 权重即资源** — 不平均分配认知资源。权重 5 追到基岩，权重 1 一句话。
4. **[HARD] 六维度全开** — 权重 ≥ 4 的概念，六个认知维度缺一不可，每维度推到天花板。
5. **[HARD] 可证伪才是假设** — P4 的每个假设必须有明确的证伪条件。不可证伪 = 删除。
6. **[HARD] 95% 才确定** — 核心结论置信度 < 95% 禁止用确定性语气。诚实标注不确定性。
7. **[HARD] 双层表达** — 每个核心结论必须同时有专家级和通俗级两种表达。
8. **[HARD] 思维链全程可见** — 零黑箱。每一步推理都显示，包括被放弃的路径。
9. **[HARD] 冲突是宝藏** — 维度间冲突、直觉与逻辑冲突、搜索与推理冲突 → 深挖，这里藏着最深的洞察。
10. **[HARD] 管线不可跳步** — P0→P1→P2→P3→P4→P5→P6，不可跳步不可倒序（P3-P5 内部循环除外）。
11. **[SOFT] 搜索防瘫痪** — P0 ≤ 20% 总时间，连续 2 轮无增量立即停止。
12. **[SOFT] 动态调权** — 分析过程中发现权重有误立即修正。
