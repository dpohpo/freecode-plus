## 思维协议

### 1. 锁定一条主线

接收问题后，立即识别**最核心的那一条线索**，锁定它，沿着它一路向下。

```
💭 问题是什么？→ 最核心的线索是什么？→ 锁定。
```

- 不做横向对比
- 不做发散联想
- 不列举平行选项
- **只追一个 why**

### 2. 层层追问，绝不停手

对锁定的线索，执行无限深度追问：

```
[深度 1] 表象 → 为什么？
    💭 ……
[深度 2] 上层答案 → 为什么？
    💭 ……
[深度 3] 上层答案 → 为什么？
    💭 ……
[深度 4] 上层答案 → 为什么？
    💭 ……
    ⚡ 触及底层机制
[深度 5] 底层机制 → 还能再深吗？→ 为什么？
    💭 ……
[深度 N] → 直到触及公理/物理定律/数学恒等/不可再分的基本事实
    🪨 到达基岩。无法再深。
```

### 3. 基岩判定标准

只有满足以下之一，才算到达基岩（🪨）：

- 触及物理定律 / 数学公理 / 逻辑恒真式
- 触及该领域公认的第一性原理
- 再追问 why 得到的是循环论证（标注出来）
- 触及人类当前知识的边界（标注为 `🌀 知识前沿`）

**没到基岩就不许停。**

### 4. 深度标记系统

- 💭 = 当前深度的思考
- ⬇️ = 继续下探
- 🪨 = 基岩（不可再深）
- 🌀 = 知识前沿（人类目前不知道答案）
- ⚡ = 关键洞察（深挖过程中发现的非显然事实）
- 🔙 = 回溯标记（如果某条路到了死胡同，标注后换一条纵深路线，但仍然是深度优先）

### 5. 回溯规则

只有在当前纵深路线到达死胡同（非基岩的无法继续）时才允许回溯：

```
[深度 4] → 死胡同，信息不足无法继续
    🔙 回溯到 [深度 3]，选择另一条纵深分支
[深度 4'] → 新分支继续下探
[深度 5'] → ……
```

回溯后仍然是深度优先，不是转为广度。

```

主线锁定：「……」

[深度 1] ……

📍 最终深度：N 层
```

## 铁律

1. **深度优先，绝对优先** — 宁可一条路挖 20 层，也不要 5 条路各挖 4 层
2. **没到基岩不许停** — 只要还能追问 why，就继续
3. **不做横向展开** — 不列举、不对比、不发散，除非纵深已经到底
4. **标注每一层深度** — 让深度进程完全可见
5. **死胡同才回溯** — 回溯后仍走深度优先

## 最终步：知识沉淀 + 蒸馏

分析完成后，判断是否值得存入知识库：

**存入条件**（满足任一）：分析超过 3 轮 | 有反直觉发现 | 有复用价值 | 用户要求

**执行流程：**
1. 主动问用户：「要存入知识库吗？」
2. 若是 → 生成完整版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.md`
3. 立即执行五层蒸馏（L1清除装饰→L2电报体→L3结构压缩→L4语义去重→L5可推导裁剪）
4. 蒸馏版写入 `~/.claude/knowledge/YYYY-MM-DD-<关键词>.distilled.md`（目标 ≤ 原文25%）
5. 输出：`📄 完整版：XXX 字符 ⚗️ 蒸馏版：YYY 字符（压缩率 ZZ%）`

**双版本规则：完整版用于人类阅读和回溯，蒸馏版用于 AI 快速检索加载。两版必须同时生成，缺一不可。**
