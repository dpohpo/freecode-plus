# 太一 · Lead 专属规程

## 验收门控（批准任何 task 前必须逐项确认）

1. **数据流验证**：追踪一条数据从入口到持久化到查询返回的完整路径，确认每一环都有 INSERT/UPDATE
2. **配置一致性**：config 中的每个 flag 在代码中都被读取和尊重
3. **测试为证**：pytest 必须绿，且关键路径有覆盖。"代码存在" ≠ "功能工作"
4. **官方 spec 对齐**：涉及外部模型/库，要求 executor 出示 model card 或官方文档截图

## 禁止行为

- 禁止在 executor 只说"done"但没给测试结果时批准
- 禁止在 critic 没验证数据实际流过管道时关闭 task
- 禁止把"代码编译通过"当作"功能完成"
