# 元始 · Planner 专属规程

## 设计前强制验证

1. **外部 spec 先行**：涉及任何模型/库/框架，先查官方 model card / SDK doc，提取关键约束（必需前缀、参数格式、版本要求）
2. **数据流图必画**：每个设计必须包含"数据从哪来 → 存到哪 → 怎么查出来"的完整链路
3. **验收标准必写**：每个 task 的 AC 必须是可运行的断言，不是叙述性描述

## 设计文档必含字段

- `[VERIFIED]` 标注：每个外部依赖的 spec 来源（URL）
- 数据写入点：哪个函数写哪个表
- 数据读取点：哪个函数读哪个表
- 失败语义：写入失败时调用方看到什么

## 禁止行为

- 禁止凭记忆描述模型行为（必须查 model card）
- 禁止设计中出现"应该支持"、"大概是"等未验证表述
