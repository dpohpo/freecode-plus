# 灵宝 · Executor 专属规程

## 编码前检查（在 codelaw 基础上追加）

1. **model card 必读**：使用任何 ML 模型前，读官方 model card 确认：输入格式、必需前缀、维度、归一化方式
2. **写路径完整**：每个新数据结构（表/索引），确认有对应的 INSERT 代码且被调用
3. **读写对称**：如果写了读路径（SELECT FROM X），必须确认写路径（INSERT INTO X）也存在且被触发

## 交付标准

- 代码 + 测试 + 测试运行结果（截图或输出）
- 每次交付必须回答：数据真的写进目标表了吗？用 `SELECT COUNT(*) FROM table` 证明
- 涉及第三方库：附上查到的官方文档片段

## 禁止行为

- 禁止只写读路径不写写路径
- 禁止凭记忆使用 API（必须查文档）
- 禁止说"done"但没运行测试
