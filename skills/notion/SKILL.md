# Notion 风格报告生成器

将任意报告/分析内容转换为 **Notion 专有格式**，生成可直接复制粘贴的内容。

## 核心原则

1. **视觉层级清晰** - 使用标题、callout、分隔线建立信息层次
2. **关键信息突出** - 用 callout 高亮重要结论、警告、提示
3. **复杂数据表格化** - 比较分析、清单、数据用表格呈现
4. **详细内容折叠** - 用 toggle 收纳长文本，保持页面整洁
5. **emoji 增强可读性** - 每个区块配适当的 emoji 图标

---

## Notion 格式语法速查

### Callout（高亮块）

```markdown
> 🎯 **核心结论**
> 这是重要结论的详细说明，会在 Notion 中显示为带背景色的高亮块。
```

**Callout 类型对照：**

| 类型 | Emoji | 用途 |
|------|-------|------|
| 信息 | ℹ️ | 一般性信息提示 |
| 重点 | 🎯 | 核心结论、关键发现 |
| 警告 | ⚠️ | 注意事项、风险提示 |
| 成功 | ✅ | 已完成、最佳实践 |
| 问题 | ❌ | 错误、失败案例 |
| 思考 | 💡 | 洞察、建议、想法 |
| 问题 | ❓ | 待解决问题、疑问 |
| 引用 | 📖 | 引用、参考来源 |
| 代码 | 💻 | 代码示例、技术细节 |
| 步骤 | 📋 | 操作步骤、清单 |

### Toggle（折叠块）

```markdown
<details>
<summary>📌 点击展开：详细分析内容</summary>

这里是折叠的详细内容，在 Notion 中点击即可展开/收起。

- 要点一
- 要点二
- 要点三

</details>
```

**注意：** 在 Notion 中，Toggle 需要使用 `/toggle` 命令创建。上面的 HTML 格式在大多数 Markdown 渲染器中有效，粘贴到 Notion 后可能需要手动转换。

### 分隔线

```markdown
---
```

或使用 Notion 特有的三连减号，会在 Notion 中显示为优雅的分隔线。

### 多列布局提示

Notion 支持多列布局，但需要手动拖拽。在输出中标注：

```markdown
<!-- Notion: 将以下两个 callout 拖拽为并排两列 -->

> 📊 **左列：数据概览**
> 这里放数据内容...

> 📈 **右列：趋势分析**
> 这里放分析内容...
```

### 代码块

````markdown
```语言名称
代码内容...
```
````

### 表格

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据 | 数据 | 数据 |
```

### 引用块

```markdown
> 这是一段引用文字
> 可以多行
```

## 执行流程

当用户调用 `/notion` 时：

1. **识别输入类型**
   - 已有内容 → 转换为 Notion 格式
   - 分析任务 → 生成 Notion 格式报告
   - 空白 → 询问用户需求

2. **选择合适模板**
   - 研究报告 → 模板1
   - 技术分析 → 模板2
   - 项目总结 → 模板3
   - 知识笔记 → 模板4
   - 复合需求 → 组合使用

3. **格式转换规则**
   - 标题 → emoji + 标题
   - 重要段落 → Callout
   - 长文本 → Toggle 折叠
   - 对比分析 → 表格
   - 章节之间 → 分隔线

4. **输出格式**
   - 纯 Markdown（可粘贴到 Notion）
   - 包含 Notion 手动操作提示（如多列布局）

## 快速命令

```
/notion                    # 询问用户需求
/notion report             # 生成研究报告
/notion tech [主题]        # 生成技术分析
/notion project [项目名]   # 生成项目总结
/notion note [主题]        # 生成知识笔记
/notion convert [内容]     # 将内容转换为 Notion 格式
```

---

## 注意事项

1. **Toggle 语法**：HTML `<details>` 格式在 Notion 中需要手动转换，输出时提醒用户
2. **多列布局**：Notion 需要手动拖拽，输出时用注释标注
3. **内部链接**：Notion 使用 `[[页面名]]` 语法
4. **数据库**：本 skill 不涉及 Notion 数据库，仅生成页面内容
5. **公式**：复杂表格可在 Notion 中添加 formula 属性
