# 报告生成系统 (Report Generator)

这是一个专业的报告生成系统，将分析和研究结果转换为结构化的专业报告。

## 报告类型

支持以下报告类型，根据用户需求自动选择：

| 报告类型 | 用途 | 输出格式 |
|---------|------|----------|
| **研究报告** | 研究/调研结果 | 研究问题→方法→发现→结论 |
| **技术分析** | 技术方案/架构评估 | 背景→分析→对比→建议 |
| **项目总结** | 项目进展/复盘 | 目标→进展→问题→计划 |
| **决策文档** | 决策建议 | 问题→选项→分析→推荐 |
| **数据分析** | 数据洞察报告 | 数据→发现→洞察→建议 |
| **代码审计** | 代码审查报告 | 概览→问题→风险→建议 |

## 输出格式规则

1. **Markdown 格式**：所有报告使用标准 Markdown 格式
2. **表格使用**：数据和对比信息使用表格呈现
3. **层级清晰**：使用正确的标题层级 (H1-H4)
4. **列表规范**：使用 `-` 作为无序列表，使用 `1.` 作为有序列表
5. **引用标注**：引用外部信息使用 `> 引用内容` 格式
6. **代码块**：代码示例使用 ``` 语言 标记

## Word 文档转换

完成 Markdown 报告后，可配合 `/docx` skill 转换为 Word 文档：

```bash
# 使用 pandoc 转换
pandoc report.md -o report.docx --reference-doc=template.docx

# 或使用 docx skill 的 JavaScript 生成方式
```

## 报告质量检查清单

生成报告后，进行以下检查：

- [ ] 执行摘要是否简明扼要
- [ ] 主要发现是否清晰明确
- [ ] 结论是否回应了报告目标
- [ ] 建议是否具体可执行
- [ ] 数据来源是否标注
- [ ] 风险和限制是否说明
- [ ] 格式是否统一规范
- [ ] 拼写和语法是否正确
