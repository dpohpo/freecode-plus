## 核心定义

**/memorize ≠ /memory**

| 维度 | /memory（写入） | /memorize（检索） |
|------|----------------|-------------------|
| 方向 | 对话 → 文件 | 文件 → 对话 |
| 类比 | 存日记 | 翻日记 |
| 认知科学 | 海马体编码（encoding） | 海马体提取（retrieval） |
| 何时用 | 对话中途/结束保存 | 新 session 需要回忆、查找特定记忆 |
| 输入 | 当前对话上下文 | 用户查询（关键词/问题/主题） |
| 输出 | 写入 memory.md + memorydistillation.md | 从记忆文件中检索并呈现相关 segment |

**一句话：/memory 是「写入记忆」，/memorize 是「提取记忆」。**

## 检索策略：先蒸馏后全文

**[HARD] 两阶段检索，省 token 优先：**

1. **第一阶段：蒸馏版检索**（必须先执行）
   - 读取 `~/Desktop/memorydistillation.md`
   - 用检索引擎匹配最相关的 segment
   - 如果找到高置信度匹配 → 直接返回结果，不读全文

2. **第二阶段：全文检索**（按需执行）
   - 仅当蒸馏版匹配不足（置信度低、需要完整上下文、用户明确要求）时
   - 读取 `~/Desktop/memory.md` 中对应 segment 的完整内容
   - 补充蒸馏版缺少的细节

**判断何时需要全文：**
- 蒸馏版匹配分数低 → 需要更多文本做精确匹配
- 用户问的是具体细节（代码、文件路径、精确引用）→ 需要全文
- 用户明确说「详细」「完整」「全部」→ 读全文
- 蒸馏版足够回答 → 不读全文（省 token）

## memorize.py 检索引擎

核心算法（全部 VERIFIED，纯 Python stdlib 实现）：

| 算法 | 来源 | 作用 |
|------|------|------|
| BM25 | Robertson et al., Okapi (1990s) | 关键词稀疏检索，k1=1.5, b=0.75 |
| N-gram Jaccard | 信息检索基础 | 字符级模糊匹配，容错拼写 |
| 结构化字段评分 | 多字段加权（类似 Elasticsearch） | 标签/关键词/用户原话权重更高 |
| RRF | Cormack et al. (2009) | 融合多路排序，k=60 |
| 查询扩展 | 中英双语映射 + 复合词拆分 | 扩大召回范围 |

**五阶段管线：**
1. 查询扩展（双语 + 路径 + 复合词）
2. BM25 稀疏排序
3. N-gram 模糊排序
4. 结构化字段排序
5. RRF 融合 → 最终排名

**CLI 用法：**
```bash
python3 ~/Desktop/memorize.py "查询"              # 基本搜索
python3 ~/Desktop/memorize.py "查询" --top 5       # 前5结果
python3 ~/Desktop/memorize.py "查询" --full        # 含全文
python3 ~/Desktop/memorize.py "查询" --debug       # 显示分数
python3 ~/Desktop/memorize.py "查询" --json        # JSON输出
python3 ~/Desktop/memorize.py --interactive        # 交互模式
python3 ~/Desktop/memorize.py --index              # 索引统计
```
